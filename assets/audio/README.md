# Generated audio

These WAV files are original, deterministic synthetic placeholders created for
Pullthread. They contain no recordings, samples, or third-party source material.

Regenerate them from the repository root with:

```sh
npm run generate:audio
```

The feedback cues are intentionally short and restrained so final production
effects can replace them without changing the semantic feedback service API.

`playful-climb-loop.wav` is the selected **Hillside Threads** arrangement: a
24-second, eight-bar loop at 80 BPM built from physically modeled fingerpicked
strings, a restrained bass bed, occasional wooden taps, and subtle cloth
texture. Its note tails and room reflections wrap across the boundary, and its
level is baked low so it remains beneath the feedback cues, including in
browsers that reserve volume control for the device buttons.
